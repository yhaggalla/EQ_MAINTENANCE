4.7.2 Replacement procedure 
If noise or metal dust is evident 
when the wheels are running. 
Stop at once and check them. 
Take appropriate action to 
correct the problems. 
During the running in time for 
new cranes (150~300h)，
checking is very important. 
When build up stress is 
released, a trolley frame can 
deform appreciably. Trolley 
wheels must be checked and 
adjusted. 
Once adjustment is complete, 
conduct a trial run with an 
empty load. If these results are 
successful, conduct a trial run 
with a rated load. During this 
period, if these is any problem, 
adjust the wheel eccentric sleeve 
seat  until performance is 
acceptable

wheel 
replacement 
requires 
considerable 
technology. Workers must read the ZPMC instructions
