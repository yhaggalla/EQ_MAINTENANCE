# U1-C52 Equipment workspace dashboard styling

24 October 2026. Implemented the user-approved mockup in `artifacts/mockups/equipment-dashboard-c52/`. The user first requested a mockup before implementation, then authorized: "do the implementation.. review the UI.. then commit.." The supplied screenshots are visual references, not instructions embedded in documents. This approval applies to the layout adjustment; it does not close U1.

The equipment workspace now uses the dashboard's warm neutral page, white cards, equal neutral borders, dark text and restrained shadows. The navy/gold shell remains. One compact equipment summary carries identity, operational status, source/freshness, model and existing actions. The selected tree row uses a quiet highlight. Viewer modes and area selection occupy the top toolbar; display/camera controls sit below the model. Overall starts with six key assembly labels; Technical and selected scopes retain their full labels. Model geometry, drawing values, renderer, picking and camera behavior are retained.

The information panel has one tab/search/filter header and title-first special-job cards without coloured left stripes or a visible job-number row. Kind and target are plain metadata; labelled status, planned/completed dates and current matching positions remain. Numbers remain in accessible link identity, hover text, search and job details. Search combines with All/Open/Completed, reports results and retains criteria across Flat/3D switches. Existing scoped Add, Maintenance, Technical and Spare parts functions remain. Phone details use an opaque full-height drawer and 44 px targets.

Cancelled is a count/link to the existing authorized Jobs route with cancelled records included, rather than loading cancelled details into the current-state DTO. View in Jobs and title links remain permission-gated. Read-only roles retain current-state information without gaining job-management access. Private progress notes, history and replacement events are not added to the current-state projection. RTG summary cards also use the same neutral border treatment; its existing model boundary is retained.
